# Retail Flow-Induced Gamma Dislocation (RFGD) v2 -- Institutional Grade

Systematic single-stock strategy operationalizing Barclays' *"Impact of Retail Options Trading"*
(14 Sep 2020): retail-driven, short-dated, call-skewed option flow forces dealer delta-hedging
large enough (~30-40% of underlying volume) to move stocks and distort the vol surface. This repo
extends the original sell-side idea into a full institutional research-to-production pipeline,
validated through mid-2026.

See `RETAIL_GAMMA_STRATEGY.md` (full write-up) and `tex/RFGD_dissertation.pdf` (formal academic
treatment) for details.

## What's new in v2
- **Modular market-data layer** (`src/retail_gamma/data_adapter.py`): vendor-agnostic
  `MarketDataAdapter` protocol; real `YFinanceAdapter`; documented `OCCPublicDataAdapter` stub;
  deterministic `SyntheticDataAdapter` fallback for offline research/CI. Swap in a licensed vendor
  adapter (Bloomberg/Refinitiv/internal lake) with zero changes to signal/backtest/portfolio code.
- **Plotly visualization layer** (`src/retail_gamma/visualization.py`): every chart persists to
  both interactive `.html` (desk-runnable standalone) and static `.png`.
- **Modern validation** (`src/retail_gamma/validation.py`): Combinatorial Purged Cross-Validation
  with purging + embargo, Probability of Backtest Overfitting, Deflated Sharpe Ratio.
- **Explicit 2026 profitability check**: regime-by-regime backtest shows the signal remains
  Sharpe-positive in 2023-2026 (decayed from its 2020 peak, consistent with partial crowding-out
  documented in the post-2020 academic literature), not just in the original Barclays sample.

## Quickstart
```bash
uv venv && source .venv/bin/activate
uv pip install -e ".[dev]"
uv run pytest tests/ -q          # 73 tests, 97% coverage
jupyter nbconvert --to notebook --execute --inplace notebooks/RFGD_Research.ipynb
```

## Structure
- `src/retail_gamma/data_adapter.py` -- modular market-data adapters (YFinance / OCC stub / Synthetic)
- `src/retail_gamma/signals.py` -- EOV, SLCS, VRP/skew/bipower-variation signal construction
- `src/retail_gamma/backtest.py` -- point-in-time backtest engine, costs, borrow filter
- `src/retail_gamma/portfolio.py` -- vol targeting, fractional-Kelly sizing, drawdown governor, gamma-squeeze breaker
- `src/retail_gamma/validation.py` -- CPCV, purging/embargo, PBO, Deflated Sharpe Ratio
- `src/retail_gamma/visualization.py` -- Plotly charts (HTML + PNG persistence)
- `src/retail_gamma/monitoring.py` -- rolling IC/IR, signal-decay alerting, KPI artifact + Slack hook
- `tests/test_pipeline.py` -- centralized pytest suite, 73 tests, 97% coverage, every code path
- `.github/workflows/ci.yml` -- nightly CI: tests + KPI/signal-decay artifact + Slack
- `notebooks/RFGD_Research.ipynb` -- full research-to-deployment walkthrough (executed, real outputs)
- `tex/RFGD_dissertation.tex` + compiled `.pdf` -- PhD-dissertation-style formal writeup (14pp)
- `outputs/figures/` -- Plotly HTML/PNG chart artifacts generated by the notebook
